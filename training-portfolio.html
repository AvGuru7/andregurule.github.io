My Philosophy on Company Training

My approach is grounded in the work of Cathy Moore (Map It: The Hands-On Guide to Strategic Training Design) and Ruth Clark (Evidence-Based Training Methods). Corporate training is less about transferring general knowledge and more about targeting the right information to drive a specific, measurable result.

It starts with clearly understanding the goal — and then honestly asking whether training is even the right solution. Sometimes the answer is a process adjustment. Sometimes it's a single well-designed job aid. Jumping straight to a course when neither is needed wastes time and erodes trust in the training function.

Adults also come to training with widely different skill levels, and effective programs account for that. Content needs to meet novices where they are without boring experienced practitioners — and those practitioners should be brought into the conversation. When skilled employees share what they know, everyone benefits, including the instructor.

The rise of AI puts corporate training — and how we work in general — at a fascinating and somewhat unsettling crossroads. I used AI to help build this website, and it is a genuinely remarkable tool. But I believe it needs to be approached with care. In the context of training, AI opens a real opportunity to cultivate new talent, if organizations are willing to invest the time to do it right. It should not replace entry-level workers. It should be used to accelerate their development — ensuring that we are building a strong, capable workforce for the future, not hollowing one out.

Training Program Development & Evaluation Framework In Pilot

Why I Built It

Training requests often arrive as a solution ("we need a course on X") before anyone has defined the problem, and evaluation gets planned after delivery, if at all. I wanted one repeatable process that makes the team confirm the real business problem, its root cause, and how success will be measured before any design work begins.

The Build

I developed the framework with Claude: a fillable Word form, with native checkboxes and text fields, that takes a program from the first conversation to final results, plus an Excel tracker with formulas and a dashboard that compares results across programs. I also built a Claude Skill that guides a designer through the same process conversationally and produces a completed form and tracker entry.

How I Tested It

Before using it on a live program, I stress-tested the framework against two mock scenarios. A warehouse accuracy problem with mixed causes showed the need for a non-training actions tracker, so results aren't attributed to training alone. A senior-leadership program with a history of failed buy-in led to new sections on leadership endorsement and hand-off. The form is now in pilot, and the next round of changes will come from real use.

CLAUDE ARTICULATE RISE HTML / JS RIGGING

Interactive Rigging Calculators

The Challenge

Basic rigging training is full of numbers learners have to apply correctly on the job: sling angle factors, tension per leg, bearing stress on hardware. A formula on a slide states the rule, but it doesn't show learners why the rule matters.

The Build

I used Claude to build self-contained HTML/JavaScript calculators, then embedded each one in an Articulate Rise lesson as a code block. Learners change the inputs and immediately see the consequences: tension climbing as sling legs flatten, or a stress gauge turning red when the hardware is too small for the load.

Drag the angle and load sliders. The rigging diagram, per-leg tension, and remaining sling capacity update in real time, with color cues as the angle approaches the 30° minimum.

function sacUpdate() {
  var angle = parseInt(document.getElementById('sac-angle').value);
  var load  = parseInt(document.getElementById('sac-load').value);
  var rad   = angle * Math.PI / 180;

  // Two-leg bridle: each leg carries half the load ÷ sin(angle)
  var slingFactor = Math.sin(rad);
  var factor      = 1 / slingFactor;               // load angle factor
  var perLeg      = (load / 2) / slingFactor;      // tension per leg (lbs)
  var pct         = Math.round(slingFactor * 100); // effective capacity %

  // Color cue: green → amber → red as capacity drops
  var barColor = pct > 70 ? '#2A9D8F' : pct > 45 ? '#DF8E1D' : '#D20F39';
  // …then redraws the SVG rigging diagram to match the new angle
}

function calc() {
  const eiw = parseFloat(document.getElementById('eiw').value); // inside width
  const hd  = parseFloat(document.getElementById('hd').value);  // hardware dia.
  const af  = parseFloat(document.getElementById('af').value);  // force (lbs)

  const ecw = surfaceFactor * eiw;          // 1.00 straight · 0.75 curved
  const lba = hd * ecw;                     // load bearing area (in²)
  const bsv = lba > 0 ? af / lba : null;    // bearing stress (lbs./in²)

  if (bsv > 7000) {
    setStatus('warn', 'Exceeds maximum — above the 7,000 lbs./in² limit');
  } else {
    setStatus('ok', 'Within limit');
  }
}

CLAUDE REACT FIREBASE IPAD

Live Training Assessment App

Why I Built It

In hands-on training, a paper quiz graded after class arrives too late to help. I wanted to see how learners answer while they're still in the room, so I can catch a misunderstanding and reteach it before the practical, and score their hands-on skills consistently instead of from memory.

The Build

I built a web app with Claude that learners use on iPads. I start a session, learners join with a 5-character code, and their answers stream to my dashboard as they type. Multiple-choice and fill-in-the-blank questions are graded automatically. I grade open answers, can override any score, and rate hands-on skills against reusable rubrics. Results export to CSV or sync to a live Google Sheet.

What It Changes in Class

The per-question results show at a glance where the group is struggling. In the sample session below, most learners calculated sling tension without applying the angle factor, a pattern I can address on the spot. The "show only incorrect answers" filter turns that into a quick reteach list, and each learner's skill evaluation is recorded on the same screen.
